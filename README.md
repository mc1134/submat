# instructions

To run this file, run `python solution.py`
You can add test cases to ./tester.py by modifying test_cases which has a definition of:
test_cases = {"NAME": {"mat": [[]], "val": 0}}
NAME is the name of the test case
mat is the mxn matrix (dimensions don't need to be specified)
val is the expected number of submatrices that have all 1s
